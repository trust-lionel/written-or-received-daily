# W.O.R.D. — Written Or Received Daily

> Send or receive a motivational postcard. A good word for someone who needs it.

**Live site:** [wordcards.co](https://wordcards.co)
**Created by:** [Lionel Mosley](https://trust-lionel.com)

---

## What is W.O.R.D.?

W.O.R.D. stands for **Written Or Received Daily**. It is a postcard platform built around one idea: the right words at the right moment can change the direction of someone's day.

Visitors can draw a random motivational postcard from the public pool, or write and send their own to someone specific. No account required. No algorithm. Just one message, one image, and a good word.

## Stack

- [Astro](https://astro.build) — static site framework
- [Tailwind CSS](https://tailwindcss.com) — utility-first styling
- [@tailwindcss/typography](https://tailwindcss.com/docs/typography-plugin) — prose rendering
- [Netlify](https://netlify.com) — hosting, forms, and blob storage
- [Unsplash API](https://unsplash.com/developers) — curated imagery
- [Netlify Blobs](https://docs.netlify.com/blobs/overview/) — postcard storage

## Getting started

```bash
# Install dependencies
npm install

# Run local dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

This project deploys automatically to Netlify on every push to `main`.

1. Connect the `written-or-received-daily` GitHub repo to Netlify
2. Netlify auto-detects Astro — build command `npm run build`, publish directory `dist`
3. Add custom domain `wordcards.co` in Netlify dashboard
4. Point GoDaddy DNS to Netlify nameservers
5. SSL provisions automatically

## SEO

- `robots.txt` — allows all crawlers, blocks `/.netlify/` and `/api/`
- `sitemap.xml` — auto-generated by `@astrojs/sitemap` on every build
- `SEO.astro` — handles meta, Open Graph, Twitter Card, and canonical URLs per page
- `netlify.toml` — www → apex redirect, HTTPS enforcement, cache headers
